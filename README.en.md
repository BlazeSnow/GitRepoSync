# Git Repo Sync

[简体中文](README.md) | English

## Introduction

> [!TIP]
> For more information about the app, see the website: <https://gitreposync.blazesnow.com/en/>

A cross-platform Git repository sync desktop tool: use a local base directory as a relay, and automatically back up repositories from the source remote (origin) to every target remote you configure — sync once, back up everywhere.

The interface supports Simplified Chinese and English, and is available on Windows, macOS (Apple Silicon / Intel) and Linux.

## Download

Head to [Releases](https://github.com/BlazeSnow/GitRepoSync/releases/latest) to get the installer for your platform:

| Platform | Installer |
| --- | --- |
| Windows x64 | `GitRepoSync_<version>_x64-setup.exe` or `.msi` |
| macOS Apple Silicon | `GitRepoSync_<version>_aarch64.dmg` |
| macOS Intel | `GitRepoSync_<version>_x64.dmg` |
| Linux x64 | `.deb` / `.rpm` / `.AppImage` |

Versions of the form `vX.Y.Z-beta.N` are beta releases: they ship features more frequently but may be less stable.
