# 功能设计

> 返回 [DEVELOPMENT.md](../DEVELOPMENT.md)

本文档记录软件各项功能的设计，随功能增加持续更新。每完成一项功能，需同步更新本文档与 CHANGELOG.md。

## 1. 用户登录

- 初始用户 `admin`，初始密码 `admin123`
- 支持持久化登录：登录状态可跨软件重启保留
- 密码可在设置页面修改

## 2. 同步仓库页面

布局分为顶部操作按钮栏和底部表格区。

**操作按钮栏：**

- 按钮“开始同步”
- 按钮“停止同步”
- 下拉选框：选择一定时间内未同步的仓库进行同步

**表格区：**

- 表格列：仓库、源地址、目标地址
- 交互：双击或右键表格行后弹窗编辑

## 3. 提供商页面

- 目前支持 GitHub、GitLab
- 用户填入对应平台的 PAT（Personal Access Token）后，列出该账户及其组织

## 4. 设置页面

- 修改账户密码
- 列出本软件仓库
- 列出本软件版本号

## 5. Agent（MCP 接入）

- 软件采用 MCP（Model Context Protocol）连接方式供 Agent 接入
- MCP 连接通过 APIKEY 鉴权
